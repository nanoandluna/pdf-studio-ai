# Roadmap

本项目优先保证 PDF 内容、保存结果和本地数据的可靠性。下列项目是方向，不是已经完成的功能或发布日期承诺。

## 已完成的 0.4.1 整理

- 保留原始 PDF 字节，修复重复保存、保存后撤销、旋转重复应用和提取丢失旋转。
- 保存采用临时文件替换；打开失败保留旧文档；关闭/切换文档提示未保存更改。
- 修复拖拽文件的读取与另存；区分各 AI Provider 的配置和密钥；支持无密钥的本机服务。
- 移除不写入 PDF 的标注原型、无效的语言/渲染质量选项、旧 AI 实现和环境专用脚本。
- 统一实际 Electron 冒烟检查；增加问题模板、贡献文档、双语 README 和可重复发布流程。

## 下一步优先级

| 优先级 | 工作 | 完成标准 |
|---|---|---|
| 高 | PDF 编辑兼容性 | 建立加密、表单、书签、签名等样本集；编辑前准确告知不支持的情况 |
| 高 | OCR 资源本地打包 | 断网首次启动也能识别中文/英文；识别资源带许可证 |
| 高 | 依赖维护 | 持续处理 npm audit 中的开发工具依赖问题，并验证升级后的 UI 与打包 |
| 中 | 标注重新实现 | 标注写入导出的 PDF；覆盖旋转、撤销、重开及中文文本 |
| 中 | AI 请求生命周期 | 取消操作真正终止网络请求；对流式工具调用分片做集成测试 |
| 中 | 页面编号统一 | 删除/排序后，工具栏、引用、搜索、AI 的可见页码规则一致 |
| 中 | 可访问性与界面翻译 | 完整键盘导航、屏幕阅读器验证，再提供真正的英文界面 |
| 后续 | 发行体验 | Windows 代码签名、自动更新；视维护能力考虑 macOS/Linux 安装包 |

## 范围

不以取代专业 PDF 排版编辑器为当前目标。涉及修改 PDF 原始内容流、电子签名或企业协作的设计，请先开 issue 讨论。提交改进时请给出使用场景和验证方式。
